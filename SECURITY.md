# Security

Chatshelf reads private data (your chat history), so security reports matter.

Please **don't open a public issue** for a vulnerability. Report it privately through GitHub: **Security → Report a vulnerability** on this repository. I'll reply as soon as I can.

In scope: anything that lets another website, another user on the machine, or the network read your chats or trigger actions through the local server (for example, bypassing the `Host` check or the per-run token).
