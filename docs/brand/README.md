# Chatshelf brand

The mark is a shelf of chats: two books (one standing, one leaning) and a speech bubble on a shelf, on a dark rounded tile.

## Files

| File | Use it for |
| --- | --- |
| [`logo.svg`](logo.svg) | Default. Light backgrounds, 32px and up |
| [`logo-reversed.svg`](logo-reversed.svg) | Dark backgrounds (#333 or darker) |
| [`logo-favicon.svg`](logo-favicon.svg) | 16–24px: browser tabs, small icons. Simplified on purpose |
| [`logo-mono-dark.svg`](logo-mono-dark.svg) | One-colour use on light backgrounds |
| [`logo-mono-light.svg`](logo-mono-light.svg) | One-colour use on dark backgrounds |
| [`logo-lockup.svg`](logo-lockup.svg) | Mark + name: banners, docs, slides. 120px wide minimum |
| [`../social-preview.png`](../social-preview.png) | GitHub social preview and link cards (1280×640) |

## Colours

| Role | Hex |
| --- | --- |
| Ink (tile, text) | `#1C1917` |
| Accent (bubble, the only accent) | `#E8590C` |
| Warm neutrals (books, shelf) | `#E7E5E4`, `#A8A29E`, `#78716C`, `#44403C` |
| Light surface (reversed tile) | `#F5F5F4` |

## Rules

- **Clear space:** keep at least a quarter of the mark's width empty around it.
- **Minimum size:** the full mark at 32px, the favicon version at 16px, the lockup at 120px wide.
- **Pick the version for the background.** Use `logo-reversed.svg` on dark backgrounds instead of adding an outline.
- **Don't** stretch, rotate, recolour, crop or rearrange the mark, and don't add shadows, gradients, outlines or effects.
- **Don't** put the mark on busy photos or patterns.

The SVGs use a 32-unit grid with 1.5-unit corner radii, and a thin gap in the tile colour keeps the bubble separate from the books in every version.
