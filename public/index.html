Tools & import

The app reads chat history from these tools. It never changes their files.

Import a ChatGPT or claude.ai export

Web chats aren't stored on your computer. Download your data (ChatGPT: Settings → Data controls → Export data. claude.ai: Settings → Privacy → Export data), then drop the .zip here. Importing again updates the same chats instead of adding duplicates.
